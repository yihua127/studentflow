# 材料核对记录

本记录说明开发阶段如何核对本地材料。原材料位于本地开发资料目录，原文件保持不变，未随公开仓库发布。以下核对结果描述当时的开发材料，不代替后续真实服务测试；最新验证范围见 `docs/TESTING.md`。

**公开版本说明：** 为移除真实课表信息，公开仓库及其历史中的 `config/scenarios.json` 已统一替换为完全虚构的示例。示例日期、可用时间、活动时间、活动名称和教室均为重新构造的数据，不代表任何学生的真实日程。`config/planning_rules.json` 保留可配置的数值默认值，并使用通用说明。

- 邮件输入共 50 封 EML；`inputs/messages.jsonl` 是同一批内容的另一种格式，不重复计数。逐封核对后，EML 文件哈希与 manifest 一致，正文和标题与 JSONL 一致。
- 其中 10 封同时包含纯文本和 HTML，只选一份正文；原 50 封均没有实际附件字节，不能据此宣称附件边界案例已经实测。
- `inputs/attachment_demos` 另有 AX01–AX03 三封模拟邮件，分别包含 PDF、DOCX、PNG。嵌入附件与 `fixtures` 中的独立副本字节一致；副本不作为额外邮件导入。
- 全部 EML 容器都是人工重建。M01–M04 的正文来自截图匿名改写，邮件头模拟、发送日期推定；其余正文为模拟。EML 导入不等于真实邮箱已接通。相对日期应依据邮件发送时间与时区，另记导入时间。
- 原开发材料中三份同内容 Excel 的哈希一致，当时仅按明确的输入字段整理开发配置。公开版本不包含这些工作簿，也不保留由真实课表整理的活动时间与地点。
- 当前 `scenarios.json` 保留 `available_slots`、`busy_events`、`tasks` 等输入结构，用虚构的充足时间和受限时间场景演示计划约束。所有任务初始为草稿；空闲时间、任务耗时、活动地点和日期均为测试设定。三餐和限制由 `planning_rules.json` 中的可配置默认值提供。
- 未将 `answers/`、manifest、人工答案工作表或混合表的期望结果列导入配置。排除 `Expected block`、`Partial block`、`Unscheduled`、`Replan added block` 等答案行。不得将本地材料根目录递归加入模型上下文或检索库。
- 原 Word 材料的不同章节包含不一致的学习例子，部分例子与用餐规则冲突。程序应以明确的规则校验，不直接复制旧例子的安排。
- 原材料中存在模拟校历说法，不能据此推断真实校历。涉及真实日期时需使用核实后的校历证据或保持待确认，不把答案表当外部事实来源。
- 固定活动缺失的结束时间、地点或适用日期需要核实，不能以保守估算代替确认。若测验已包含在一个课程时段内，不重复增加占用或通勤。公开示例中的活动与课程材料没有对应关系。
- 40 分钟通勤只是可修改默认值；去程、返程、三餐冲突和晚归需另行确认。默认值已含暂定缓冲，不自动另加缓冲。学习时段边界不等于到家时限。
- 该材料包是开发集。正式效果应使用未参与调试的邮件、附件和问题另测，记录真实结果，不预填成功率。
- 本记录对应的材料核对没有调用收费 API，也没有验证真实邮箱授权与下载、图片 OCR 或地图服务。不能以 EML 导入、文件存在或模拟时长代替真实服务验证；后续已验证和未验证的功能分别记录在测试文档中。
