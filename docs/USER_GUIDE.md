# Using StudentFlow

## Inbox (Gmail)

Connect Gmail, refresh the inbox, select a message and choose **Open message**. Review the message text before creating a task. The message and its attachments stay on your computer unless you explicitly choose AI extraction.

To add a task, enter a name, a deadline in Singapore time, an estimated study duration and a matching passage from the message. Confirm the review and select **Save task**. If the deadline or estimated time is missing, the task is saved as **Needs details** and will not be scheduled. Saving the same task name from the same message updates that record.

AI extraction is optional. If configured, **Extract tasks with AI** offers suggestions for review. **Use this suggestion** fills the task form; it does not confirm or save the task automatically. Original message quotations retain their original language.

## Tasks

View saved tasks, their deadlines and their source messages. Review supporting text or download the task list as CSV. To complete missing information, reopen the source message and save the same task name with the corrected details.

## Study Plan

1. Add the dates and times when you are available to study.
2. Add classes, meetings and other commitments. For in-person events, specify travel time each way.
3. Review **Study preferences**, including the daily limit, study-session duration and breaks. Meals remain reserved at the displayed times.
4. Select **Generate study plan**. Review both the scheduled sessions and any work that remains unscheduled.
5. Confirm your review and select **Save plan**. Download the schedule as CSV if needed.

Changes to tasks, availability or commitments require a fresh plan. Availability is entered manually; it is not automatically synced from a calendar service. Planning preferences and confirmed plans are saved on your device.

## Attachments

Open a message with an attachment, then select **Read attachments** in the Attachments tab. Search using keywords from the document and inspect the matching source text. PDF and Word documents are supported. Images and scanned pages that need text recognition are identified clearly but are not transcribed by this version.
