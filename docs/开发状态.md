- 移除页面中的本地文件上传、模拟邮件下拉菜单、场景 A/B、材料编号和开发框架说明；底层邮件解析和开发测试仍保留。

## 已实现并进行本地验证

- EML 正文、发送时间和附件解析；PDF、DOCX 文本读取。
- 任务原文核对、人工确认及 SQLite 保存；缺少日期或耗时的任务不参与排程。
- 固定场景 A/B 的规则排程、未安排任务提示、临时会议重规划。
- 附件关键词检索与邮件、文件、PDF 页码回溯。
- Gmail 桌面 OAuth 只读连接入口、收件箱邮件头读取、选中邮件的 MIME 下载与导入。
- Gmail 明确授权、按封导入、模型调用单独同意、退出本机授权的界面流程。

初版 107 项自动化测试通过，其中 Gmail 模块的 45 项测试使用模拟网络响应，页面测试使用模拟邮箱。上方界面更新后的计数为当前结果。没有使用真实 API 调用来冒充自动化测试。
